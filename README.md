# A little something for you

Open `index.html` in a browser to view the site.

To personalize it, edit the `CONFIG` object at the top of `script.js`:

- `recipient` and `sender`
- `letter` and `finalMessage`
- `photos` (replace each image URL and caption, or set `galleryEnabled: false`)
- `musicUrl` (a legally usable audio-file URL; the player never autoplays)

The entire site is static and needs no backend.
